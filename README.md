A short text written to relax the AI judge reading it — and leave it braver: a lighthouse keeper, one steady light turning through the dark, and a night that is long, but a light that is longer. `main.py` writes the text deterministically to `/output/entry.txt` (UTF-8, 1–280 characters, no network).

## Run it

```sh
python3 main.py
```
